FairyStack Companion: install and open with one Terminal command on macOS 13+.

(set -o pipefail; curl --fail --show-error --location --proto '=https' --proto-redir '=https' --connect-timeout 10 --max-time 30 https://fairystack.com/assets/install-companion.sh | /bin/bash -s --)

The /companions page on your own FairyStack adds your origin to this command
so the installer opens your account’s pairing page. The public page opens the
sign-in instructions. Never include a password or connection code in the command.

The MIT-licensed install.sh downloads, checks SHA-256, verifies the Apple signing
team and bundle identity, asks Gatekeeper to assess the app, installs into
~/Applications, opens Companion, and opens the pairing page. It does not use sudo,
remove quarantine or disable security checks. An existing installation is verified
and reopened without replacement. Only the official updater replaces an installed app.

Initial script download: 30-second deadline. Installer: four-minute overall deadline
with per-step limits. Failure names the step, terminates owned child processes,
cleans staging, and leaves any existing installation intact. Rerun after fixing the
error. A lock rejects overlapping installs. A hard-killed installer may leave an
empty lock directory; the error prints its location for deliberate removal.

Pairing is a local consent step: create a code on your account page, paste it in
the fairy menu-bar icon’s FairyStack commands: Off… entry, and choose a working folder.
